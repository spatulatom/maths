# Starting point: tool-fluent, math-rusty career switcher

The user is moving into data analysis from an unrelated field, with a self-taught coding background (strong JavaScript). They know Excel including pivot tables and Power Query, the main SQL concepts, and a little Python. They studied math long ago and believe they have forgotten even the basics.

**Evidence**: self-reported in the first session (not yet tested; lesson 0001 diagnostic will confirm).

**Implications**: anchor every math idea to something they can already do in Excel or code (a formula, a pivot, a JS expression). Start from arithmetic and percentages unless the diagnostic shows otherwise.
