# Math for Data Analysis

A self-paced course on the math behind data analysis: percentages, averages, growth, spread, correlation, uncertainty, and the logic behind joins and filters. It's built as preparation for the Microsoft Power BI Data Analyst certificate and the PL-300 exam.

Each lesson is a single HTML page with an interactive chart or simulator, worked examples in Excel and Power BI, and an 8-question quiz.

## How to use it

Open any file in [`lessons/`](lessons/) in a browser. No install or server is needed. Start with [0001](lessons/0001-where-am-i-diagnostic.html), or use the [roadmap](reference/roadmap.html).

| Folder | What's in it |
|---|---|
| `lessons/` | 19 lessons, each linking to the previous and next |
| `assets/` | Shared styles and interactive components (box plot, histogram, scatter, sampler, A/B test, joins…) |
| `reference/` | Roadmap, glossary, and a tools & languages overview |
| `learning-records/` | Dated notes on progress and quiz results |
