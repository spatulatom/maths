# Math for Data Analysis Resources

## Knowledge

- [Microsoft Learn: PL-300 study guide (skills measured)](https://learn.microsoft.com/certifications/resources/study-guides/pl-300)
  The official exam scope: prepare data, model data, visualize and analyze, manage and secure. Use for: checking that each math topic actually serves the exam and job.
- [Coursera: Microsoft Power BI Data Analyst Professional Certificate](https://www.coursera.org/professional-certificates/microsoft-power-bi-data-analyst)
  The course the user will take next. Eight courses, starting with Excel data prep and ending with PL-300 prep. Use for: aligning lesson order with what the course assumes.
- [Khan Academy: Pre-algebra](https://www.khanacademy.org/math/pre-algebra)
  Free, high-quality refreshers on fractions, decimals, negatives, order of operations, and percentages. Use for: rebuilding forgotten basics.
- [Khan Academy: Statistics and Probability](https://www.khanacademy.org/math/statistics-probability)
  Free course with practice. Use for: mean, median, spread, distributions, correlation, sampling.
- [StatQuest with Josh Starmer (YouTube)](https://www.youtube.com/@statquest)
  Short, clear visual explanations by a former biostatistics researcher. Use for: standard deviation, p-values, regression, intuition-first.
- [OpenIntro Statistics (free textbook)](https://www.openintro.org/book/os/)
  Rigorous but readable free textbook used in university intro courses. Use for: when a deeper, trustworthy written explanation is needed.

- [Lumen Learning: Outliers (Introductory Statistics)](https://courses.lumenlearning.com/suny-fmcc-introstats1/chapter/outliers/)
  Open-licence textbook chapter. Use for: the 1.5 × IQR rule with worked examples, and "outliers need investigation".
- [Microsoft Support: Create a box and whisker chart](https://support.microsoft.com/office/create-a-box-and-whisker-chart-62f4219f-db4b-4754-aca8-4743f6190f0d)
  Excel's built-in box plot, including the inclusive/exclusive median quartile setting. Use for: Excel practice on spread and outliers.

- [Microsoft Learn: Use grouping and binning in Power BI Desktop](https://learn.microsoft.com/power-bi/create-reports/desktop-grouping-and-binning)
  Official how-to for bins on numeric and date fields. Use for: building histograms in Power BI (PL-300 "grouping, binning, and clustering").

- [Tyler Vigen: Spurious Correlations](https://tylervigen.com/spurious-correlations)
  Hundreds of real but meaningless correlations between unrelated series. Use for: making "correlation is not causation" stick.

- [Microsoft Learn: Power Query data profiling tools](https://learn.microsoft.com/power-query/data-profiling-tools)
  Column quality, distribution, and profile, which by default use only the first 1,000 rows. Use for: the "profiling is a sample" point (lesson 0013).
- [Microsoft Learn: Merge queries overview](https://learn.microsoft.com/power-query/merge-queries-overview)
  The six join kinds, with a page per kind. Use for: joins (lesson 0016).
- [Microsoft Learn: Understand star schema and the importance for Power BI](https://learn.microsoft.com/power-bi/guidance/star-schema)
  Fact vs dimension tables, and one-to-many relationships. Use for: cardinality and modelling (lesson 0018).
- [Microsoft Learn: Model relationships](https://learn.microsoft.com/power-bi/transform-model/desktop-relationships-understand)
  Cardinality and cross-filter direction. Use for: PL-300 modelling questions.
