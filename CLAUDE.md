# Math for Data Analysis (teach project)

This folder is a `/teach` project. The teach skill can only be started by the user.

At the start of a session:

- If the user hasn't run `/teach`, remind them in one line to run it.
- Read MISSION.md, NOTES.md, and the latest files in learning-records/ before answering questions about progress or next steps. If a `private/` folder exists, read it too.

This repo is public. Personal details about the learner (background, job, career plans) go in `private/`, which is gitignored, and never in tracked files.

Lessons are local files only. Don't publish them as Artifacts unless the user asks for that.
