# Uses the tools through the UI; DAX and M are new

The user works with Excel, Power Query, and pivot tables through the interface. They know there are languages "behind" these tools but deliberately haven't opened them, to avoid getting lost in the weeds. DAX was new to them when it appeared in lessons 0002–0003.

**Evidence**: the user's own question, 2026-10-27.

**Implications**: DAX in math lessons stays a labelled preview, translated into plain words or an Excel formula. The strongest bridge to DAX measures is the user's existing pivot-table intuition: a measure recalculates for every cell, like a pivot value. Don't teach M or VBA. Expect DAX itself to come from the Coursera certificate; this course supplies the math that DAX measures express.
