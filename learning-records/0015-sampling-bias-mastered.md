# Sampling and bias mastered

Lesson 0013 quiz scored 8/8. The learner can tell the two ways a sample can be wrong apart. Sampling error is random wobble: it shrinks with the square root of the sample size, so 4× the people halves it. Bias is a systematic lean that a bigger sample can't fix.

The questions covered:

- sample vs population (400 of 20,000)
- bigger random samples wobble less, but don't remove bias
- square root rule (100 → 400 halves the wobble)
- a self-selected 50,000-vote poll is still biased
- survivorship bias (asking current customers why people cancel)
- Power Query profiling reads only the first 1,000 rows by default
- random sampling in Excel (sort by `=RAND()`, take the top N)
- spaced review: AND rule in a funnel (0.6 × 0.5 = 30%)
