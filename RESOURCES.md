# Math for Data Analysis Resources

## Knowledge

- [Microsoft Learn: PL-300 study guide (skills measured)](https://learn.microsoft.com/certifications/resources/study-guides/pl-300)
  The official exam scope: prepare data, model data, visualize and analyze, manage and secure. Use for: checking that each math topic actually serves the exam and job.
- [Coursera: Microsoft Power BI Data Analyst Professional Certificate](https://www.coursera.org/professional-certificates/microsoft-power-bi-data-analyst)
  The course the user will take next. Eight courses, starting with Excel data prep and ending with PL-300 prep. Use for: aligning lesson order with what the course assumes.
- [Khan Academy: Pre-algebra](https://www.khanacademy.org/math/pre-algebra)
  Free, high-quality refreshers on fractions, decimals, negatives, order of operations, and percentages. Use for: rebuilding forgotten basics.
- [Khan Academy: Statistics and Probability](https://www.khanacademy.org/math/statistics-probability)
  Free course with practice. Use for: mean, median, spread, distributions, correlation, sampling.
- [StatQuest with Josh Starmer (YouTube)](https://www.youtube.com/@statquest)
  Short, clear visual explanations by a former biostatistics researcher. Use for: standard deviation, p-values, regression, intuition-first.
- [OpenIntro Statistics (free textbook)](https://www.openintro.org/book/os/)
  Rigorous but readable free textbook used in university intro courses. Use for: when a deeper, trustworthy written explanation is needed.

## Wisdom (Communities)

- [r/dataanalysis](https://www.reddit.com/r/dataanalysis/)
  Use for: career-switch questions, portfolio feedback, "what do analysts really use" questions.
- [r/PowerBI](https://www.reddit.com/r/PowerBI/)
  Active community. Use for: DAX and modelling questions, PL-300 exam experiences.
- [Microsoft Fabric Community (Power BI forums)](https://community.fabric.microsoft.com/)
  Official forums with Microsoft MVPs answering. Use for: specific Power BI / DAX problems.
